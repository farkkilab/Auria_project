The following scripts contain the code for the analysis/figure generation of the spatial transcritomics:

>> Spatial_signatures.R 
Contains with the exploration of the visium slides, and the computation of the oxstress/GCLCVIM signatures at the slide level.


>> TNBCs_spatial_preparation.ipynb
Contains the exploration of the deconvolution for each of the spots, and the preparation of the data for the hotspot analysis


>> Hotspot_calculation_and_slides_plots.ipynb
Contains the hotspot analysis and distance calculations, and the code to obtain the H&E figure slides, the signatures displayed in the slide, the hotspots displayed in the sldie and the proportions pies


>> Spatial_figures.R
Contains the code to obtain the barplot, cleveland, dotplots refered to the spatial analysis.
